# COLORS persona: current sources

Reviewed 2 November 2026. The previous large specification mixed voice guidance with a retired scripted gatekeeper flow. That obsolete flow specification has been removed; this entry point remains for existing code/UI references.

- **Voice and current prompt:** `lib/colors-forum-persona.ts`, composed by `lib/colors-conversation-profile.ts` and the COLORS adapter. This is separate from the public demo personas' database voice.
- **Approved membership context:** [membership conversation brief](docs/colors-forum-membership-brief.md). It contains project context, not a promise of live host features.
- **Conversation-quality review:** [guide and rubric](docs/colors-conversation-guide-and-rubric.md). These scores evaluate transcripts, not applicants.
- **Runtime, stopping and assessment:** [COLORS engine](docs/colors-conversation-engine.md).
- **Permissions, records and clone updates:** [persona ownership](docs/persona-ownership.md).
- **Final decisions/access:** [client policy](docs/client-decision-policy.md), independently from conversational recommendation.

For another brand or public demo, use [demo persona creation](docs/demo-persona-creation.md). Do not copy an old COLORS interview/consent script, universal score threshold or pass/reject prompt into it.
